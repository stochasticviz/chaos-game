## throwing an error is the 2nd best outcome
The best outcome for executing a bit of code is success. The second best outcome is throwing an error. It's a bad thing to silently fall back on some reasonable value. Fallbacks are bad. Always throw exceptions if something is missing or not the format or type or value that we need.
